# Конфиденциальность InstaFlow

InstaFlow не собирает, не хранит и не передаёт персональные данные на сторонние серверы.

- Расширение работает только на страницах `instagram.com`.
- Ссылки на медиа используются локально браузером для запуска загрузок.
- Настройки папок хранятся локально средствами `chrome.storage.local` в профиле Chrome.
- Расширение не содержит аналитики, рекламы и удалённого исполняемого кода.

Разрешение `downloads` нужно для сохранения файлов, `storage` — для настроек, `contextMenus` — для команды правой кнопки мыши, `scripting` и доступ к Instagram — для кнопки на публикации и чтения доступного пользователю медиа.

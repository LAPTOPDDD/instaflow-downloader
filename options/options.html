Организация файлов

Chrome сохраняет файлы внутри стандартной папки «Загрузки».

Пример пути Загрузки/Instagram/nasa/2026-10-23_ABC123_video.mp4

Почему нельзя выбрать любую папку? Из соображений безопасности Chrome разрешает расширениям автоматически сохранять только внутри вашей папки «Загрузки».
